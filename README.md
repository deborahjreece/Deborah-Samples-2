Summary of Samples

Amex API Management OAuth Guide (Sample_D_Reece4.pdf)
An internal American Express integration guide walking external clients through the API Management Gateway's OAuth flow — covering application registration during onboarding, obtaining and refreshing access tokens, and calling protected API/resource endpoints with those tokens. It includes a document revision history showing multiple review cycles, indicating it was a formally maintained internal technical spec rather than public-facing documentation.

Amex for Developers – ATM Locator (Sample from Web Portal.pdf)
A public-facing API reference page from the Amex Developer Portal documenting the ATM Locator resource, which lets client apps search for American Express–accepting ATMs by address, ZIP code, or geolocation. It details the GET /atms and HEAD /atms endpoints, pagination via limit/offset parameters, required API key security headers, and links to sample Java and .NET client libraries.

Android Mobile ID SDK Integration Guide.pdf
A developer integration guide for IDEMIA's Mobile ID SDK on Android, aimed at "Relying Parties" who want to embed identity-verification and biometric enrollment capabilities (facial and document recognition) into their own apps. It lays out prerequisites (Kotlin/Android Studio knowledge, minimum SDK version, required licenses), environment setup steps like Gradle configuration, and the core enrollment use cases: registration, authorization, and authentication.

BioServices_API_Guide.pdf
An overview of IDEMIA's Biometric Services platform, a REST API for face detection/recognition plus a WebCapture SDK for liveness detection from video. It explains the service-provider/end-user model and walks through common workflows — such as reference image verification and one-to-one face match — including step-by-step process flows and UML sequence diagrams.

Hosted APIs_D Reece Sample.docx
A technical reference for integrating native lottery systems with IGT's Remote Game Server (RGS), which hosts eInstant HTML5 games for state iLottery programs. It describes the RGS architecture (cloud and in-state deployment options, reporting, jackpot and bonus features) and documents the back-office API set — including calls like gameInProgress — that operators use to manage player sessions across desktop, mobile, and tablet.

IDEMIA Biometric SDK Integration Guide (Reece Sample.pdf)
A "Capture SDK" integration guide for mobile developers, covering how to add IDEMIA's biometric SDK (formerly Morpho Bio SDK) to an Android project via Gradle, including credentials and dependency setup for biometric vs. document-scanning modules. It documents the SDK's six core components (capture, matching, document reading, local template storage, image utilities, and license management) along with key design considerations like permission handling and licensing requirements.

IDEMIA_Getting Started_VerifySDK (Create Sample Windows App, D Reece Sample.pdf)
A step-by-step setup guide for testing IDEMIA's Verify SDK sample Windows application, requiring admin privileges, developer mode, a webcam (for QR scanning), and Bluetooth (for BLE data transfer). It walks through installing the provided app package via PowerShell and configuring document namespaces and fields for an identity-verification test session, pairing with a mobile device running the Mobile ID app.

Verify by IDEMIA Product Guide 2.1 (Revised D Reece.pdf)
An internal product guide (version 2020.4) for the full IDEMIA Verify Product Suite, intended for internal/business-unit use rather than customers. It covers the product's components, verification capabilities, supported platforms and devices, applicable international standards, and the structure of the Verify SDK package and its exposed APIs.
